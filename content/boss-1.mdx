## রাউন্ড ১: দোকান সাজাও

```sql
CREATE DATABASE shop CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE shop;

CREATE TABLE products (
  id        INT AUTO_INCREMENT PRIMARY KEY,
  name      VARCHAR(100),
  category  VARCHAR(50),
  price     DECIMAL(8,2),
  stock     INT,
  expiry    DATE          -- চাল, লবণের মতো জিনিসে মেয়াদ নেই, তাই NULL
);

INSERT INTO products (name, category, price, stock, expiry) VALUES
  ('মিনিকেট চাল (৫ কেজি)', 'চাল-ডাল', 420.00, 25, NULL),
  ('মসুর ডাল (১ কেজি)', 'চাল-ডাল', 135.00, 40, NULL),
  ('সয়াবিন তেল (১ লি.)', 'তেল', 175.00, 0, '2027-03-01'),
  ('সরিষার তেল (৫০০ মি.লি.)', 'তেল', 160.00, 12, '2027-01-15'),
  ('গুঁড়া দুধ (৫০০ গ্রাম)', 'দুধ', 380.00, 8, '2026-12-20'),
  ('তরল দুধ (১ লি.)', 'দুধ', 95.00, 30, '2026-11-20'),
  ('চিনি (১ কেজি)', 'মুদি', 130.00, 50, NULL),
  ('লবণ (১ কেজি)', 'মুদি', 42.00, 60, NULL),
  ('চা পাতা (৪০০ গ্রাম)', 'পানীয়', 210.00, 5, '2027-06-30'),
  ('বিস্কুট', 'নাস্তা', 25.00, 100, '2026-12-05'),
  ('চানাচুর', 'নাস্তা', 60.00, 0, '2026-11-30');
```

`price`-এর জন্য `DECIMAL(8,2)` কেন? সর্বোচ্চ 999999.99 টাকা, মুদি দোকানের জন্য যথেষ্ট, আর টাকা কখনো `FLOAT`-এ না।

## রাউন্ড ২: খোঁজাখুঁজি

<Quest id="1" title="কোনটা ফুরিয়ে গেছে?">
যেসব পণ্যের স্টক শূন্য, তাদের নাম আর দাম দেখাও।

<Solution>
```sql
SELECT name, price FROM products WHERE stock = 0;
```

| name | price |
| --- | --- |
| সয়াবিন তেল (১ লি.) | 175.00 |
| চানাচুর | 60.00 |
</Solution>
</Quest>

<Quest id="2" title="শিগগির অর্ডার দিতে হবে">
যেসব পণ্য এখনো আছে কিন্তু ১০টা বা তার কম, কম থেকে বেশি স্টক অনুযায়ী সাজিয়ে।

<Solution>
```sql
SELECT name, price, stock FROM products
WHERE stock BETWEEN 1 AND 10
ORDER BY stock;
```

| name | price | stock |
| --- | --- | --- |
| চা পাতা (৪০০ গ্রাম) | 210.00 | 5 |
| গুঁড়া দুধ (৫০০ গ্রাম) | 380.00 | 8 |

`stock <= 10` লিখলে শূন্য স্টকের জিনিসও আসত; প্রশ্নটা ছিল "এখনো আছে", তাই নিচের সীমা 1।
</Solution>
</Quest>

<Quest id="3" title="তেল আর দুধ">
নামে "তেল" বা "দুধ" আছে এমন সব পণ্য, দামি থেকে সস্তা।

<Solution>
```sql
SELECT name, price FROM products
WHERE name LIKE '%তেল%' OR name LIKE '%দুধ%'
ORDER BY price DESC;
```

| name | price |
| --- | --- |
| গুঁড়া দুধ (৫০০ গ্রাম) | 380.00 |
| সয়াবিন তেল (১ লি.) | 175.00 |
| সরিষার তেল (৫০০ মি.লি.) | 160.00 |
| তরল দুধ (১ লি.) | 95.00 |
</Solution>
</Quest>

<Quest id="4" title="মেয়াদ শেষের পথে">
যেসব পণ্যের মেয়াদ ১ ডিসেম্বর ২০২৬-এর আগে শেষ হবে। মেয়াদহীন পণ্য যেন না আসে।

<Solution>
```sql
SELECT name, expiry FROM products
WHERE expiry IS NOT NULL AND expiry < '2026-12-01'
ORDER BY expiry;
```

| name | expiry |
| --- | --- |
| তরল দুধ (১ লি.) | 2026-11-20 |
| চানাচুর | 2026-11-30 |

আসলে `expiry < '2026-12-01'` নিজেই `NULL` বাদ দিয়ে দেয় (কারণ `NULL`-এর তুলনা কখনো সত্যি হয় না), তবু `IS NOT NULL` লিখে উদ্দেশ্যটা পরিষ্কার রাখা ভালো অভ্যাস।
</Solution>
</Quest>

<Quest id="5" title="কোন কোন ক্যাটাগরি?">
দোকানে মোট কোন কোন ক্যাটাগরির জিনিস আছে, বর্ণানুক্রমে, প্রতিটা একবার।

<Solution>
```sql
SELECT DISTINCT category FROM products ORDER BY category;
```

চাল-ডাল, তেল, দুধ, নাস্তা, পানীয়, মুদি।
</Solution>
</Quest>

<Quest id="6" title="কোথায় সবচেয়ে বেশি টাকা আটকে আছে?">
প্রতিটা পণ্যের মোট মজুদ-মূল্য (দাম × স্টক) হিসাব করে `value` নামে দেখাও, সবচেয়ে বেশি ৩টা।

<Solution>
```sql
SELECT name, price * stock AS value
FROM products
ORDER BY value DESC
LIMIT 3;
```

| name | value |
| --- | --- |
| মিনিকেট চাল (৫ কেজি) | 10500.00 |
| চিনি (১ কেজি) | 6500.00 |
| মসুর ডাল (১ কেজি) | 5400.00 |

`ORDER BY`-তে Alias চলে, `WHERE`-এ চলে না। কেন, তা লেভেল ৮-এ।
</Solution>
</Quest>

## রাউন্ড ৩: হিসাব বদলাও

<Quest id="7" title="নতুন চালান এলো">
তিনটা কাজ: (ক) সয়াবিন তেল ২০টা এসেছে, স্টকে যোগ করো; (খ) চিনির দাম ৫ টাকা বেড়েছে; (গ) নতুন পণ্য "ডিম (১ ডজন)", ক্যাটাগরি "মুদি", দাম 150, স্টক 20, মেয়াদ 2026-11-28।

<Solution>
```sql
UPDATE products SET stock = stock + 20 WHERE id = 3;
UPDATE products SET price = price + 5 WHERE id = 7;
INSERT INTO products (name, category, price, stock, expiry)
VALUES ('ডিম (১ ডজন)', 'মুদি', 150.00, 20, '2026-11-28');
```

`stock = 20` না লিখে `stock = stock + 20` লিখেছি, যাতে আগের স্টক যাই থাকুক, তার সাথে যোগ হয়।
</Solution>
</Quest>

<Quest id="8" title="মেয়াদোত্তীর্ণ মাল সরাও">
তরল দুধের মেয়াদ (২০২৬-১১-২০) আজকের (২০২৬-১১-১৬) পরে, তাই ওটা থাকবে। কিন্তু চাচা বললেন, "যেগুলোর মেয়াদ ১৫ নভেম্বর ২০২৬ বা তার আগে শেষ হয়েছে, সেগুলো তালিকা থেকে মুছে দাও।" আগে কোনগুলো মুছবে দেখে নাও, তারপর মোছো।

<Solution>
```sql
-- ১. আগে দেখে নাও
SELECT id, name, expiry FROM products WHERE expiry <= '2026-11-15';
-- ২. তারপর মোছো
DELETE FROM products WHERE expiry <= '2026-11-15';
```

প্রথম Query কোনো Row ফেরত দেয় না, তাই `DELETE`-ও কিছু মোছে না। আগে `SELECT` চালানোর অভ্যাস তোমাকে এখানে বাঁচিয়ে দিল: কিছু মুছবে না, সেটা আগেই জানা গেল।
</Solution>
</Quest>

<Boss title="ঈদের ছাড়ের ব্যানার">
চাচা ঈদ উপলক্ষে "তেল" আর "দুধ" ক্যাটাগরির ২০০ টাকার কম দামের পণ্যে ১০% ছাড় দেবেন, তবে শুধু যেগুলো স্টকে আছে। ব্যানারের জন্য Query লেখো যেটা দেখাবে "পণ্য", "আগের দাম", "ছাড়ের দাম", ছাড়ের দাম অনুযায়ী সস্তা থেকে দামি। (রাউন্ড ৩-এ সয়াবিন তেলের স্টক ২০ হয়েছে, সেটা ধরে নাও।)

<Solution title="ইঙ্গিত">
ছাড়ের দাম = দাম × ০.৯০। শর্ত তিনটা: ক্যাটাগরি (`IN`), দাম ২০০-এর কম, স্টক শূন্যের বেশি। আর `ORDER BY`-এ `SELECT`-এর Alias চলে, কারণ `ORDER BY` চলে `SELECT`-এর পরে।
</Solution>

<Solution>
```sql
SELECT name AS `পণ্য`,
       price AS `আগের দাম`,
       price * 0.90 AS `ছাড়ের দাম`
FROM products
WHERE category IN ('তেল', 'দুধ')
  AND price < 200
  AND stock > 0
ORDER BY `ছাড়ের দাম`;
```

| পণ্য | আগের দাম | ছাড়ের দাম |
| --- | --- | --- |
| তরল দুধ (১ লি.) | 95.00 | 85.5000 |
| সরিষার তেল (৫০০ মি.লি.) | 160.00 | 144.0000 |
| সয়াবিন তেল (১ লি.) | 175.00 | 157.5000 |

`IN` ব্যবহার করায় `OR`-এর অগ্রাধিকারের ফাঁদ এড়ানো গেল। ছাড়ের দামে দশমিকের পরে চার অঙ্ক কেন, আর কীভাবে সুন্দর করে দুই অঙ্কে আনা যায় (`ROUND`), সেটা পরের জোনের প্রথম লেভেলেই।
</Solution>
</Boss>
