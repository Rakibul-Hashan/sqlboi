## String Function: লেখার যন্ত্র

### CONCAT: জোড়া লাগাও

```sql
SELECT CONCAT(name, ' (ক্লাস ', class, '-', section, ')') AS পরিচয়
FROM students
LIMIT 3;
```

| পরিচয় |
| --- |
| রাফি (ক্লাস 8-A) |
| নুসরাত (ক্লাস 8-A) |
| তানভীর (ক্লাস 8-B) |

সংখ্যা (`class`) নিজে থেকেই লেখায় বদলে গেছে। কিন্তু সাবধান: `CONCAT`-এর কোনো একটা অংশ `NULL` হলে পুরো ফলাফলই `NULL` হয়ে যায়। তখন `CONCAT_WS` (With Separator) কাজে লাগে, যেটা `NULL` অংশগুলো বাদ দিয়ে জোড়ে: `CONCAT_WS(', ', name, phone)`।

### দৈর্ঘ্য: CHAR_LENGTH বনাম LENGTH

```sql
SELECT name, CHAR_LENGTH(name) AS অক্ষর, LENGTH(name) AS বাইট
FROM students
LIMIT 3;
```

| name | অক্ষর | বাইট |
| --- | --- | --- |
| রাফি | 4 | 12 |
| নুসরাত | 6 | 18 |
| তানভীর | 6 | 18 |

"রাফি" চার অক্ষরের (র, া, ফ, ি), কিন্তু `LENGTH` বলছে ১২! কারণ `LENGTH` **বাইট** গোনে, আর UTF-8-এ প্রতিটা বাংলা অক্ষর ৩ বাইট জায়গা নেয়। ইংরেজিতে দুটো একই উত্তর দেয়, তাই অনেকেই পার্থক্যটা টের পায় না।

<Remember>
**বাংলা (বা যেকোনো অ-ইংরেজি) লেখার দৈর্ঘ্য মাপতে সবসময় `CHAR_LENGTH`।** "নাম সর্বোচ্চ ৫০ অক্ষর" যাচাই করতে `LENGTH` ব্যবহার করলে বাংলা নাম মাত্র ১৬-১৭ অক্ষরেই আটকে যাবে।
</Remember>

### কাটা আর বদলানো

```sql
SELECT UPPER('rafi'), LOWER('DHAKA'), TRIM('   নাম   '),
       REPLACE('017-1100-0001', '-', ''),
       LEFT('01711000001', 3), SUBSTRING('01711000001', 4, 4);
```

| UPPER('rafi') | LOWER('DHAKA') | TRIM('   নাম   ') | REPLACE(...) | LEFT(..., 3) | SUBSTRING(..., 4, 4) |
| --- | --- | --- | --- | --- | --- |
| RAFI | dhaka | নাম | 01711000001 | 017 | 1100 |

| Function | কাজ |
| --- | --- |
| `UPPER(s)`, `LOWER(s)` | বড় হাতের / ছোট হাতের (বাংলায় এর কোনো প্রভাব নেই) |
| `TRIM(s)` | দুই পাশের বাড়তি স্পেস ফেলে দেয় |
| `REPLACE(s, a, b)` | `s`-এর ভেতরের সব `a`-কে `b` দিয়ে বদলায় |
| `LEFT(s, n)`, `RIGHT(s, n)` | বাঁ বা ডান থেকে `n`টা অক্ষর |
| `SUBSTRING(s, শুরু, কয়টা)` | মাঝখান থেকে কেটে নেওয়া; গোনা শুরু **1** থেকে, 0 থেকে না |

একটা বাস্তব কাজ: নোটিশ বোর্ডে ফোন নম্বর লুকিয়ে দেখানো।

```sql
SELECT name, CONCAT(LEFT(phone, 3), '*****', RIGHT(phone, 3)) AS masked
FROM students
WHERE phone IS NOT NULL
LIMIT 3;
```

| name | masked |
| --- | --- |
| রাফি | 017*****001 |
| নুসরাত | 018*****002 |
| মীম | 019*****004 |

## Number Function: সংখ্যার যন্ত্র

```sql
SELECT ROUND(4.567, 2), ROUND(4.5), CEIL(4.1), FLOOR(4.9),
       ABS(-7), MOD(17, 5), TRUNCATE(4.567, 1);
```

| ROUND(4.567, 2) | ROUND(4.5) | CEIL(4.1) | FLOOR(4.9) | ABS(-7) | MOD(17, 5) | TRUNCATE(4.567, 1) |
| --- | --- | --- | --- | --- | --- | --- |
| 4.57 | 5 | 5 | 4 | 7 | 2 | 4.5 |

| Function | কাজ | মনে রাখার কৌশল |
| --- | --- | --- |
| `ROUND(x, d)` | `d` দশমিক ঘরে রাউন্ড | ৫ বা বেশি হলে ওপরে |
| `CEIL(x)` | ওপরের পূর্ণসংখ্যা | Ceiling = ছাদ |
| `FLOOR(x)` | নিচের পূর্ণসংখ্যা | Floor = মেঝে |
| `TRUNCATE(x, d)` | রাউন্ড না করে কেটে ফেলা | কাঁচি |
| `MOD(a, b)` বা `a % b` | ভাগশেষ | জোড়-বেজোড় যাচাই: `MOD(roll, 2) = 0` |
| `ABS(x)` | ঋণাত্মক চিহ্ন বাদ | দূরত্ব |

`CEIL` কোথায় লাগে? ৪৫ জন ছাত্রকে ১০ জনের দলে ভাগ করলে কয়টা দল? `CEIL(45 / 10)` = ৫, কারণ শেষের ৫ জনের জন্যও একটা দল লাগবে।

## Date Function: সময়ের যন্ত্র

| Function | কী দেয় |
| --- | --- |
| `NOW()` | এই মুহূর্তের তারিখ আর সময় |
| `CURDATE()` | আজকের তারিখ |
| `YEAR(d)`, `MONTH(d)`, `DAY(d)` | তারিখের বছর, মাস, দিন আলাদা করে |
| `DATEDIFF(a, b)` | দুই তারিখের মধ্যে কত দিন |
| `TIMESTAMPDIFF(একক, a, b)` | বছর/মাস/দিন... যেকোনো এককে পার্থক্য |
| `DATE_ADD(d, INTERVAL n DAY)` | তারিখের সাথে যোগ (DAY, MONTH, YEAR...) |
| `DATE_FORMAT(d, ফরম্যাট)` | তারিখ নিজের পছন্দমতো দেখানো |

```sql
SELECT DATE_FORMAT('2011-03-14', '%d/%m/%Y') AS a,
       DATE_FORMAT('2011-03-14', '%W, %e %M %Y') AS b,
       DATE_ADD('2026-11-16', INTERVAL 30 DAY) AS c,
       DATEDIFF('2026-12-16', '2026-11-16') AS d;
```

| a | b | c | d |
| --- | --- | --- | --- |
| 14/03/2011 | Monday, 14 March 2011 | 2026-12-16 | 30 |

`%d` = দিন (দুই অঙ্কে), `%m` = মাস (অঙ্কে), `%Y` = চার অঙ্কের বছর, `%M` = মাসের নাম, `%W` = বারের নাম, `%e` = দিন (শুরুর শূন্য ছাড়া)।

### বয়স বের করা

```sql
SELECT name, TIMESTAMPDIFF(YEAR, birth_date, CURDATE()) AS age
FROM students;
```

`TIMESTAMPDIFF(YEAR, ...)` শুধু পূর্ণ বছর গোনে, তাই জন্মদিন না আসা পর্যন্ত বয়স বাড়বে না, ঠিক বাস্তবের মতো।

<Tip title="বয়স কেন টেবিলে রাখি না?">
বয়স প্রতিদিন বদলায়, জন্মতারিখ কখনো বদলায় না। তাই টেবিলে রাখো **জন্মতারিখ**, আর বয়স দরকার হলে Query-তে হিসাব করো। নাহলে প্রতি বছর সবার বয়স হাতে আপডেট করতে হবে। এ ধরনের হিসাব-করা মানকে বলে **Derived Attribute**, লেভেল ১৪-তে আবার দেখা হবে।
</Tip>

## CASE: SQL-এর "যদি-তাহলে"

আমাদের স্কুলের নিয়মে GPA থেকে গ্রেড বানাই:

```sql
SELECT name, gpa,
  CASE
    WHEN gpa = 5.00 THEN 'A+'
    WHEN gpa >= 4.00 THEN 'A'
    WHEN gpa >= 3.50 THEN 'A-'
    WHEN gpa >= 3.00 THEN 'B'
    WHEN gpa IS NULL THEN 'ফল আসেনি'
    ELSE 'C'
  END AS grade
FROM students
ORDER BY gpa DESC;
```

| name | gpa | grade |
| --- | --- | --- |
| নুসরাত | 5.00 | A+ |
| লামিয়া | 4.95 | A |
| সাদিয়া | 4.80 | A |
| রাফি | 4.50 | A |
| মীম | 4.25 | A |
| ইমরান | 4.00 | A |
| তানভীর | 3.75 | A- |
| জুবায়ের | 3.50 | A- |
| আরিফ | 2.90 | C |
| ফারিহা | NULL | ফল আসেনি |

`CASE` ওপর থেকে নিচে পড়ে আর **প্রথম সত্যি শর্তে থেমে যায়**। তাই নুসরাত (5.00) `>= 4.00` শর্তও পূরণ করলেও A+ পেয়েছে, কারণ ওপরের লাইনটা আগে মিলেছে। ক্রম উল্টে দিলে সবাই A পেয়ে যেত।

একটা Column-এর নির্দিষ্ট মান মেলাতে ছোট রূপও আছে:

```sql
SELECT name,
  CASE class
    WHEN 8 THEN 'জুনিয়র'
    WHEN 9 THEN 'মাধ্যমিক'
    ELSE 'পরীক্ষার্থী'
  END AS ধাপ
FROM students;
```

আর মাত্র দুটো বিকল্প হলে MySQL-এর নিজস্ব `IF(শর্ত, সত্যি হলে, মিথ্যা হলে)`:

```sql
SELECT name, IF(phone IS NULL, 'নেই', 'আছে') AS ফোন FROM students;
```

<BugMonster title="যন্ত্রের গোলমাল">

**১. নামের জায়গায় `à¦°à¦¾à¦«à¦¿` জাতীয় আজব লেখা।** এটা **Mojibake**: বাংলা UTF-8 লেখাকে কেউ ভুল করে Latin1 হিসেবে পড়েছে। ডেটা ঢোকানো বা পড়ার সময় সংযোগের Character Set `utf8mb4` ছিল না। PHP-তে `$db->set_charset("utf8mb4")`, টার্মিনালে `mysql --default-character-set=utf8mb4`। একবার ভুল এনকোডিংয়ে ঢুকে যাওয়া ডেটা পরে ঠিক করা কষ্টের, তাই শুরু থেকেই সব জায়গায় `utf8mb4`।

**২. `CONCAT` হঠাৎ `NULL` দিচ্ছে।** কোনো একটা অংশ `NULL`। `CONCAT_WS` বা `IFNULL(phone, '')` দিয়ে মোড়াও।

**৩. লেখা আর সংখ্যার নিঃশব্দ রূপান্তর।**

```sql
SELECT '5' + 3, 'abc' + 1;   -- উত্তর 8 আর 1, কোনো error ছাড়াই!
```

MySQL লেখাকে চুপচাপ সংখ্যায় বদলে নেয়, না পারলে 0 ধরে (আর শুধু একটা warning দেয়)। লেখা জোড়ার জন্য `+` না, `CONCAT`।

**৪. ভাগে অবাক ফল।** `10 / 3` দেয় `3.3333`, আর পূর্ণসংখ্যার ভাগ চাইলে `10 DIV 3` = `3`। শূন্য দিয়ে ভাগ করলে MySQL error না দিয়ে `NULL` ফেরত দেয়।

**৫. `CASE`-এর ক্রম ভুল।** সবচেয়ে কড়া শর্ত (A+) সবার ওপরে, সবচেয়ে ঢিলা শর্ত নিচে।

</BugMonster>

<Quest id="2" title="জন্মদিনের মাস">
প্রতিটা ছাত্রের নাম, জন্মমাসের নাম, আর জন্মতারিখ "দিন/মাস" ফরম্যাটে (যেমন 14/03), মাস অনুযায়ী সাজিয়ে।

<Solution>
```sql

FROM students
ORDER BY MONTH(birth_date), DAY(birth_date);
```

`ORDER BY MONTHNAME(...)` করলে বর্ণানুক্রমে সাজাত (April, August, December...), তাই সাজাতে `MONTH()` সংখ্যা ব্যবহার করেছি।
</Solution>
</Quest>

<Quest id="3" title="জোড় না বেজোড়?">
প্রতিটা ছাত্রের রোল জোড় না বেজোড়, `CASE` বা `IF` দিয়ে দেখাও। (পরীক্ষার হলে জোড় রোল বাঁ সারিতে, বেজোড় ডান সারিতে বসবে।)

<Solution>
```sql
SELECT name, roll, IF(MOD(roll, 2) = 0, 'বাঁ সারি', 'ডান সারি') AS seat
FROM students
ORDER BY roll;
```
</Solution>
</Quest>

<Boss title="রেজাল্ট কার্ড">
প্রতিটা ছাত্রের জন্য একটা রেজাল্ট কার্ড-লাইন বানাও, যেখানে থাকবে:

- `card`: "নাম (ক্লাস-সেকশন)" যেমন "রাফি (8-A)"
- `percent`: GPA × 20, রাউন্ড করে পূর্ণসংখ্যা; GPA না থাকলে "—"
- `grade`: ওপরের স্কুলের নিয়মে
- `age`: পূর্ণ বছরে, আজকের তারিখ ধরে
- সাজানো: গ্রেড ভালো থেকে খারাপ, একই গ্রেডে নাম অনুযায়ী

<Solution title="ইঙ্গিত ১">
প্রতিটা Column আলাদা Function: `card`-এর জন্য `CONCAT`, `percent`-এর জন্য `ROUND` আর `NULL` সামলাতে `IFNULL`, `grade`-এর জন্য `CASE`, বয়সের জন্য `TIMESTAMPDIFF`।
</Solution>

<Solution title="ইঙ্গিত ২">
`CASE`-এ ক্রমটাই নিয়ম: প্রথম যে `WHEN` সত্য, সেটাই জেতে, তাই কড়া শর্ত (5.00) আগে লেখো। আর `NULL`-এর জন্য আলাদা `WHEN gpa IS NULL` লাগবে।
</Solution>

<Solution>
```sql
SELECT CONCAT(name, ' (', class, '-', section, ')') AS card,
       IFNULL(ROUND(gpa * 20), '—') AS percent,
       CASE
         WHEN gpa = 5.00 THEN 'A+'
         WHEN gpa >= 4.00 THEN 'A'
         WHEN gpa >= 3.50 THEN 'A-'
         WHEN gpa >= 3.00 THEN 'B'
         WHEN gpa IS NULL THEN 'ফল আসেনি'
         ELSE 'C'
       END AS grade,
       TIMESTAMPDIFF(YEAR, birth_date, CURDATE()) AS age
FROM students
ORDER BY gpa IS NULL, gpa DESC, name;
```
