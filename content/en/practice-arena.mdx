## Easy

<Challenge id="1" tier="easy" title="Members in Riaz’s programs" anchorPrefix="en-q">

List members enrolled in at least one program taught by Riaz. Return each member once, ordered by member ID.

<Solution title="Hint 1">
Join member → enrolled → program → trainer.
</Solution>

<Solution title="Hint 2">
Group by member ID and name so repeated enrollments don’t duplicate a member or merge two people with the same name.
</Solution>

<Solution title="Show solution">
```sql
SELECT m.name
FROM member m
JOIN enrolled e ON e.member_id = m.id
JOIN program p  ON p.id = e.program_id
JOIN trainer t  ON t.id = p.trainer_id
WHERE t.name = 'রিয়াজ'
GROUP BY m.id, m.name
ORDER BY m.id;
```
</Solution>

</Challenge>

<Challenge id="2" tier="easy" title="Employees hired after 2022" anchorPrefix="en-q">

Show the name, outlet ID, and hire date of employees in outlets 2 or 5 who joined after 2022. List the earliest hires first.

<Solution title="Hint 1">
Use an IN list for the two outlets.
</Solution>

<Solution title="Hint 2">
Start at 2023-01-01 to exclude every date in 2022.
</Solution>

<Solution title="Show solution">
```sql
SELECT name, outlet_id, join_date
FROM employee
WHERE outlet_id IN (2, 5)
  AND join_date > '2022-12-31'
ORDER BY join_date;
```
</Solution>

</Challenge>

<Challenge id="3" tier="easy" title="Books nobody bought" anchorPrefix="en-q">

Find books with no purchases. Express your answer in SQL and relational algebra.

<Solution title="Hint 1">
Test for the absence of a purchase matched by book ID.
</Solution>

<Solution title="Hint 2">
Subtract purchased book IDs from all book IDs, then join to book for titles.
</Solution>

<Solution title="Show solution">
```sql
SELECT b.title
FROM book b
WHERE NOT EXISTS (SELECT 1 FROM purchase p WHERE p.book_id = b.id);
```

Relational algebra: subtract the purchased book IDs from all book IDs, then join the remaining IDs back to the book relation and project the titles.
</Solution>

## Medium

<Challenge id="5" tier="medium" title="Employees and their managers" anchorPrefix="en-q">

Show every employee’s name and their manager’s name. Keep employees who have no manager.

<Solution title="Hint 1">
Use separate aliases for employees and managers in a self join.
</Solution>

<Solution title="Hint 2">
Put the employee table on the left so rows with a missing manager are preserved.
</Solution>

<Solution title="Show solution">
```sql
SELECT e.name AS employee, m.name AS manager
FROM employee e
LEFT JOIN employee m ON m.id = e.manager_id
ORDER BY e.id;
```
</Solution>

</Challenge>

<Challenge id="6" tier="medium" title="High-selling categories in 2025" anchorPrefix="en-q">

Show book categories with more than 1,500 in total 2025 sales, calculated as copies × price. Include the sales amount and sort highest first.

<Solution title="Hint 1">
Calculate each purchase’s revenue before summing.
</Solution>

<Solution title="Hint 2">
Put the year filter in WHERE and the total threshold in HAVING.
</Solution>

<Solution title="Show solution">
```sql
SELECT b.category, SUM(p.qty * b.price) AS sales
FROM purchase p
JOIN book b ON b.id = p.book_id
WHERE p.purchased_on >= '2025-01-01' AND p.purchased_on < '2026-01-01'
GROUP BY b.category
HAVING SUM(p.qty * b.price) > 1500
ORDER BY sales DESC;
```
</Solution>

</Challenge>

<Challenge id="7" tier="medium" title="Average program enrollments" anchorPrefix="en-q">

Find the average number of programs per member, rounded to two decimal places. Include members with no enrollments.

<Solution title="Hint 1">
Start with member and LEFT JOIN enrolled.
</Solution>

<Solution title="Hint 2">
Count a non-NULL enrollment column per member, then average the counts.
</Solution>

<Solution title="Show solution">
```sql
SELECT ROUND(AVG(cnt), 2) AS avg_programs
FROM (
  SELECT m.id, COUNT(e.program_id) AS cnt
  FROM member m
  LEFT JOIN enrolled e ON e.member_id = m.id
  GROUP BY m.id
) t;
```
</Solution>

</Challenge>

<Challenge id="8" tier="medium" title="Salaries above the outlet average" anchorPrefix="en-q">

Create a view named above_outlet_avg containing employees whose pay exceeds the average for their own outlet.

<Solution title="Hint 1">
Correlate the salary subquery by outlet ID, or join to one average per outlet.
</Solution>

<Solution title="Show solution">
```sql
CREATE OR REPLACE VIEW above_outlet_avg AS
SELECT e.name, e.outlet_id, e.salary
FROM employee e
WHERE e.salary > (SELECT AVG(e2.salary) FROM employee e2 WHERE e2.outlet_id = e.outlet_id);

SELECT * FROM above_outlet_avg ORDER BY outlet_id;
```

<Challenge id="9" tier="medium" title="Buyers of the most expensive books" anchorPrefix="en-q">

List everyone who bought a book at the highest price, including buyers of any books tied at that price.

<Solution title="Hint 1">
Compare the book’s price with MAX(price) so all tied titles qualify.
</Solution>

```sql
SELECT c.name
FROM customer c
JOIN purchase p ON p.customer_id = c.id
```

## Hard

<Challenge id="10" tier="hard" title="Members in every one of Riaz’s programs" anchorPrefix="en-q">

Find the members enrolled in every program Riaz teaches.

<Solution title="Hint 1">
Find the required set of Riaz’s programs first.
</Solution>

<Solution title="Hint 2">
A member qualifies when there is no required program they are missing.
</Solution>

<Solution title="Show solution">
```sql
SELECT m.name
FROM member m
WHERE NOT EXISTS (
  SELECT 1
  FROM program p
  JOIN trainer t ON t.id = p.trainer_id
  WHERE t.name = 'রিয়াজ'
    AND NOT EXISTS (
      SELECT 1 FROM enrolled e
      WHERE e.member_id = m.id AND e.program_id = p.id
    )
)
ORDER BY m.id;
```
</Solution>

</Challenge>

<Challenge id="11" tier="hard" title="Top-spending book buyers by city" anchorPrefix="en-q">

For every city, report the customer name and total book spending for the highest spender. Include all ties.

<Solution title="Hint 1">
Calculate one spending total per customer in a CTE.
</Solution>

<Solution title="Hint 2">
Rank the totals within each city and keep rank 1.
</Solution>

<Solution title="Show solution">
```sql
WITH spend AS (
  SELECT c.city, c.name, SUM(p.qty * b.price) AS total
  FROM customer c
  JOIN purchase p ON p.customer_id = c.id
  JOIN book b     ON b.id = p.book_id
  GROUP BY c.id, c.city, c.name
),
ranked AS (
  SELECT s.*, RANK() OVER (PARTITION BY city ORDER BY total DESC) AS rk
  FROM spend s
)
SELECT city, name, total
FROM ranked
WHERE rk = 1
ORDER BY total DESC;
```
</Solution>

</Challenge>

<Challenge id="12" tier="hard" title="Running innings scores" anchorPrefix="en-q">

Show each team’s innings and cumulative score through that innings.

<Solution title="Hint 1">
Use SUM with OVER, partition by team, and order the innings within each team.
</Solution>

<Solution title="Show solution">
```sql
SELECT t.name, i.played_on, i.score,
       SUM(i.score) OVER (PARTITION BY i.team_id ORDER BY i.played_on) AS running
FROM innings i
JOIN team t ON t.id = i.team_id
ORDER BY i.team_id, i.played_on;
```
</Solution>

</Challenge>

<Challenge id="13" tier="hard" title="Players matching the league’s run statistics" anchorPrefix="en-q">

Create a view named runs_extremes containing players whose run totals equal the league maximum, minimum, or average.

<Solution title="Hint 1">
Compute the three aggregates separately from the row-level comparisons.
</Solution>

<Solution title="Show solution">
```sql
CREATE OR REPLACE VIEW runs_extremes AS
SELECT name, runs
FROM player
WHERE runs = (SELECT MAX(runs) FROM player)
   OR runs = (SELECT MIN(runs) FROM player)
   OR runs = (SELECT AVG(runs) FROM player);

SELECT * FROM runs_extremes;
```
</Solution>

## Boss challenges

<Challenge id="14" tier="boss" title="Employee reporting paths" anchorPrefix="en-q">

For each employee show their name, how many levels below Karim they are, and the full reporting path from Karim. Karim’s depth is zero. Sort by the path.

<Solution title="Hint 1">
Use a recursive CTE with Karim as the anchor and direct reports as the recursive step.
</Solution>

<Solution title="Hint 2">
Cast the anchor’s path to a wide character type so the recursive part can append names.
</Solution>

<Solution title="Show solution">
```sql
WITH RECURSIVE chain AS (
  SELECT id, name, manager_id, 0 AS level, CAST(name AS CHAR(200)) AS path
  FROM employee
  WHERE manager_id IS NULL
  UNION ALL
  SELECT e.id, e.name, e.manager_id, c.level + 1, CONCAT(c.path, ' → ', e.name)
  FROM employee e
  JOIN chain c ON e.manager_id = c.id
)
SELECT name, level, path
FROM chain
ORDER BY path;
```
</Solution>

</Challenge>

<Challenge id="15" tier="boss" title="Changes in monthly spending" anchorPrefix="en-q">

For each buyer, show monthly spending in 2025 and the change from their previous month with a purchase.

<Solution title="Hint 1">
Aggregate by customer and calendar month first.
</Solution>

<Solution title="Hint 2">
Use LAG ordered by month within each customer. A month with no purchases need not be generated.
</Solution>

<Solution title="Show solution">
```sql
WITH monthly AS (
  SELECT c.name, DATE_FORMAT(p.purchased_on, '%Y-%m') AS month,
         SUM(p.qty * b.price) AS spent
  FROM customer c
  JOIN purchase p ON p.customer_id = c.id
  JOIN book b     ON b.id = p.book_id
  WHERE p.purchased_on >= '2025-01-01' AND p.purchased_on < '2026-01-01'
  GROUP BY c.id, c.name, month
)
SELECT name, month, spent,
       spent - LAG(spent) OVER (PARTITION BY name ORDER BY month) AS change_amt
FROM monthly
ORDER BY name, month;
```
</Solution>

</Challenge>

<Challenge id="16" tier="boss" title="Outlet report card" anchorPrefix="en-q">

Show one row per outlet with its area, employee count, total salary, and highest-paid employee’s name. Keep empty outlets with zero count and payroll. Sort by total payroll.

<Solution title="Hint 1">
Build the payroll summary and the highest-paid employee result separately.
</Solution>

<Solution title="Hint 2">
Start the final query from outlet and LEFT JOIN the two results. Use a tie-breaker to return one top employee per outlet.
</Solution>

<Solution title="Show solution">
```sql
WITH top_paid AS (
  SELECT outlet_id, name
  FROM (
    SELECT outlet_id, name,
           ROW_NUMBER() OVER (PARTITION BY outlet_id ORDER BY salary DESC, id) AS rn
    FROM employee
  ) x
  WHERE rn = 1
)
SELECT o.area,
       COUNT(e.id) AS staff,
       COALESCE(SUM(e.salary), 0) AS payroll,
       tp.name AS top_earner
FROM outlet o
LEFT JOIN employee e  ON e.outlet_id = o.id
LEFT JOIN top_paid tp ON tp.outlet_id = o.id
GROUP BY o.id, o.area, tp.name
ORDER BY payroll DESC;
```
</Solution>

</Challenge>
