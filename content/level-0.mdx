## খাতা, Excel, নাকি Database?

ডেটা মানে তথ্য: নাম, রোল, নম্বর, দাম, তারিখ। এগুলো রাখার তিনটা সাধারণ উপায় পাশাপাশি দেখি।

| প্রশ্ন | খাতা | Excel | Database |
| --- | --- | --- | --- |
| ১০ লাখ লাইনের মধ্যে একটা খুঁজতে কত সময়? | ঘণ্টা থেকে দিন | ফাইল ভারী হয়ে আটকে যায় | এক সেকেন্ডের কম (ঠিকমতো সাজালে) |
| একসাথে ১০০ জন লিখলে? | অসম্ভব | একজন লিখলে বাকিরা আটকে থাকে | সমস্যা নেই |
| ভুল ডেটা আটকানো (যেমন বয়স -৫) | মানুষের চোখের ওপর ভরসা | কিছুটা পারে | নিয়ম বানিয়ে পুরোপুরি আটকানো যায় |
| ওয়েবসাইট বা অ্যাপ থেকে ব্যবহার | যায় না | কষ্টসাধ্য | এর জন্যই বানানো |
| কে কী দেখতে পারবে | তালা-চাবি | পুরো ফাইল শেয়ার করতে হয় | প্রতিটা ইউজারের আলাদা অনুমতি |

Excel খারাপ কিছু না; ছোট হিসাবের জন্য দারুণ। কিন্তু যখন ডেটা অনেক, ইউজার অনেক, আর ভুলের সুযোগ নেই, তখন লাগে **Database**। আর সেই Database চালানোর সফটওয়্যারকে বলে **DBMS** (Database Management System)। **MySQL** হলো পৃথিবীর সবচেয়ে জনপ্রিয় ফ্রি DBMS-গুলোর একটা।

## আমাদের চারপাশে Database

তুমি প্রতিদিন না জেনেই অনেকগুলো Database ব্যবহার করো:

- **Facebook:** তুমি যখন লাইক দাও বা কমেন্ট করো, সেটা কোথাও জমা হয়। Facebook-এর নিজের ইঞ্জিনিয়ারিং ব্লগে লেখা আছে, লাইক, কমেন্ট, শেয়ারের মতো সোশ্যাল কাজের পেটাবাইট-পেটাবাইট ডেটা তারা MySQL দিয়ে সামলায় ([সূত্র](https://engineering.fb.com/2016/08/31/core-infra/myrocks/))।
- **bKash:** প্রতিটা Send Money একটা লেনদেন। টাকা এক অ্যাকাউন্ট থেকে কমবে আর অন্যটায় বাড়বে, দুটোই একসাথে, নাহলে কোনোটাই না। এই "হয় সব, নয় কিছুই না" নিয়মটা Database-এর একটা মূল ক্ষমতা, যেটা আমরা লেভেল ১৮-তে শিখব।
- **Daraz:** হাজার হাজার পণ্য, দাম, স্টক, অর্ডার। "৫০০ টাকার নিচে লাল জুতা" খুঁজলে পেছনে একটা Query চলে।
- **স্কুলের রেজাল্ট:** রোল নম্বর দিলে রেজাল্ট আসে, মানে লাখো ছাত্রের মধ্য থেকে ঠিক তোমারটা খুঁজে আনা হলো।

<Note title="একটু সাবধানতা">
bKash বা Daraz ঠিক কোন DBMS ব্যবহার করে, সেটা তারা প্রকাশ্যে জানায়নি বলে আমরা দাবি করছি না। আমরা শুধু বলছি, এমন কাজের জন্য একটা Database লাগবেই।
</Note>

## কীভাবে কাজ করে?

তুমি যখন ব্রাউজারে রেজাল্টের পেজে রোল লিখে Enter চাপো, তখন চারটা ধাপ ঘটে:

<Flow steps={["Browser রোল পাঠায়", "Server (PHP) Query পাঠায়", "MySQL উত্তর খোঁজে", "Server পেজ বানিয়ে ফেরত দেয়"]} />

1. **Browser** তোমার লেখা রোল নম্বর Server-এ পাঠায়।
2. **Server**-এ একটা প্রোগ্রাম (যেমন PHP) MySQL-কে একটা প্রশ্ন পাঠায়। এই প্রশ্নকে বলে **Query**, আর প্রশ্নের ভাষাটার নাম **SQL** (Structured Query Language)।
3. **MySQL** খাতা ঘেঁটে উত্তর বের করে দেয়।
4. Server উত্তরটা HTML পেজ বানিয়ে তোমার Browser-এ ফেরত পাঠায়।

<Analogy>
**Server** = একটা ডেস্ক। **Database** = ডেস্কে রাখা একটা খাতা (যেমন `school`)। **Table** = খাতার একটা নির্দিষ্ট ছক (যেমন `students`)। **Row** = ছকের একটা লাইন (একজন ছাত্র)। **Column** = ছকের একটা ঘর (নাম, রোল...)।

এক ডেস্কে অনেক খাতা থাকতে পারে, আর এক খাতায় অনেক ছক।
</Analogy>

## নিজের ডেস্ক সাজাও

এবার নিজের কম্পিউটারে একটা "ডেস্ক" বসাই। সবচেয়ে সহজ উপায় **XAMPP**, যেটা একবারে Web Server (Apache), PHP আর Database সব ইনস্টল করে দেয়।

1. [apachefriends.org](https://www.apachefriends.org) থেকে তোমার অপারেটিং সিস্টেমের XAMPP নামাও আর ইনস্টল করো।
2. **XAMPP Control Panel** খোলো। **Apache** আর **MySQL**-এর পাশের **Start** চাপো। দুটোই সবুজ হলে ডেস্ক রেডি।
3. ব্রাউজারে যাও `http://localhost/phpmyadmin`। এটা Database দেখার আর চালানোর একটা ওয়েব টুল।

<Note title="ছোট্ট একটা সত্যি কথা">
XAMPP-এর বাটনে "MySQL" লেখা থাকলেও ২০১৫ সাল থেকে এর ভেতরে আসলে থাকে **MariaDB** ([সূত্র](https://en.wikipedia.org/wiki/XAMPP))। MariaDB বানিয়েছে MySQL-এরই আদি নির্মাতাদের একটা দল, আর দুটো প্রায় যমজ। এই বইয়ের প্রায় সব কোড দুটোতেই চলবে; যেখানে পার্থক্য আছে, সেখানে আলাদা করে বলে দেব। বইয়ের সব উদাহরণ MySQL 8-এ চালিয়ে পরীক্ষা করা।
</Note>

এবার phpMyAdmin-এর ওপরে **SQL** ট্যাবে ক্লিক করো, নিচের কোডটা পেস্ট করে **Go** চাপো:

```sql
CREATE DATABASE school CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE school;
CREATE TABLE students (
  id   INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(100)
);
```

এখনই প্রতিটা শব্দ না বুঝলেও চলবে, লেভেল ১-এ ভেঙে ভেঙে বুঝব। আপাতত এটুকু জানো: প্রথম লাইন একটা খাতা বানাল (`school`), আর শেষেরটা খাতায় একটা ছক বানাল (`students`), যার দুটো ঘর: `id` আর `name`। `utf8mb4` অংশটা বলে দিল, এই খাতায় বাংলা লেখাও ঠিকঠাক থাকবে।

## ধাপ ১: শুধু HTML, আর সমস্যাটা চোখে দেখা

XAMPP ইনস্টল ফোল্ডারের ভেতরে `htdocs` নামে একটা ফোল্ডার আছে (Windows-এ সাধারণত `C:\xampp\htdocs`)। এর ভেতরে `school` নামে একটা ফোল্ডার বানাও, আর তাতে `index.html` ফাইল:

```html
<form>
  <input name="name" placeholder="তোমার নাম">
  <button>জমা দাও</button>
</form>
```

ব্রাউজারে `http://localhost/school/index.html` খোলো, একটা নাম লিখে জমা দাও, তারপর পেজ রিফ্রেশ করো। নামটা কোথায়? **হারিয়ে গেছে।** HTML শুধু দেখাতে পারে, কিছু মনে রাখতে পারে না। মনে রাখার জন্যই লাগে Database।

## ধাপ ২: PHP যোগ করে নাম জমানো

`index.html` মুছে একই ফোল্ডারে `index.php` বানাও:

```php
<?php
$db = new mysqli("localhost", "root", "", "school");
$db->set_charset("utf8mb4");

if (isset($_POST["name"])) {
    $name = $_POST["name"];
    $db->query("INSERT INTO students (name) VALUES ('$name')"); // ⚠️ এখানে একটা ফাঁক আছে
}
?>
<form method="post">
  <input name="name" placeholder="তোমার নাম">
  <button>জমা দাও</button>
</form>
```

নতুন কী হলো:

- `new mysqli(...)` দিয়ে PHP তোমার ডেস্কে (MySQL) ঢুকল। চারটা জিনিস দিলাম: কোথায় (`localhost`), কে (`root`), পাসওয়ার্ড (XAMPP-এ শুরুতে খালি), আর কোন খাতা (`school`)।
- `INSERT INTO students (name) VALUES (...)` হলো আমাদের প্রথম আসল SQL Query। মানে: "`students` ছকে একটা নতুন লাইন যোগ করো, যার `name` ঘরে এই নামটা।"

এবার `http://localhost/school/` খুলে নাম জমাও, তারপর phpMyAdmin-এ `students` টেবিল খুলে দেখো। নামটা বসে আছে!

## ধাপ ৩: জমা নাম পেজে ফিরিয়ে আনা

এখন জমা নামগুলো পেজেই দেখাই। `index.php`-এর একদম শেষে এটুকু যোগ করো:

```php
<ul>
<?php
$result = $db->query("SELECT name FROM students");
while ($row = $result->fetch_assoc()) {
    echo "<li>" . htmlspecialchars($row["name"]) . "</li>";
}
?>
</ul>
```

`SELECT name FROM students` মানে: "`students` ছক থেকে সবার `name` দাও।" রিফ্রেশ করো, ব্রাউজার বন্ধ করো, কম্পিউটার রিস্টার্ট দাও; নাম থেকেই যাবে। অভিনন্দন, তুমি মাত্র একটা আসল ডেটাবেস-চালিত ওয়েবসাইট বানালে! 🎉

<Remember>
এই ডেমোর `INSERT` লাইনে ইচ্ছে করে একটা নিরাপত্তা-ফাঁক রেখে দিয়েছি, যার নাম **SQL Injection**। নিজের কম্পিউটারে শেখার জন্য ঠিক আছে, কিন্তু **এই কোড কখনো ইন্টারনেটে তুলবে না।** লেভেল ১৯-এ আমরা ফাঁকটা খুঁজে বের করে বন্ধ করব।
</Remember>

<BugMonster title="সাধারণ ভুল">

**১. XAMPP-এ MySQL বা Apache স্টার্ট হচ্ছে না।** প্রায়ই অন্য কোনো প্রোগ্রাম আগে থেকেই একই Port (দরজা) দখল করে রাখে: Apache-এর জন্য 80, MySQL-এর জন্য 3306। Control Panel-এর লগে "Port in use" দেখলে ওই প্রোগ্রাম বন্ধ করো, বা XAMPP-এর **Config** থেকে Port বদলাও।

**২. বাংলা নাম জমালে `???` দেখাচ্ছে।** Database বা সংযোগ বাংলা বোঝে না। ঠিক করতে দুটো জিনিস লাগবে: Database বানানোর সময় `CHARACTER SET utf8mb4`, আর PHP-তে `$db->set_charset("utf8mb4");`।

**৩. `Unknown database 'school'`।** Database-টা বানানো হয়নি, বা নামের বানান ভুল। phpMyAdmin-এর বাঁ পাশে `school` আছে কি না দেখো।

**৪. নামের মধ্যে `'` দিলে (যেমন `O'Neil`) error আসছে।** এটাই সেই ফাঁকের প্রথম লক্ষণ! নামের `'` চিহ্নটা SQL-এর `'` চিহ্নের সাথে গুলিয়ে যাচ্ছে। লেভেল ১৯ পর্যন্ত অপেক্ষা করো।

</BugMonster>
