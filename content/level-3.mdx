## SELECT: যা দেখতে চাও

```sql
SELECT * FROM students;
```

`*` মানে "সব Column"। কিন্তু বাস্তবে প্রায়ই শুধু কয়েকটা দরকার হয়:

```sql
SELECT name, class, city FROM students;
```

| name | class | city |
| --- | --- | --- |
| রাফি | 8 | ঢাকা |
| নুসরাত | 8 | চট্টগ্রাম |
| তানভীর | 8 | ঢাকা |
| মীম | 9 | সিলেট |
| আরিফ | 9 | রাজশাহী |
| সাদিয়া | 9 | ঢাকা |
| জুবায়ের | 10 | খুলনা |
| ফারিহা | 10 | চট্টগ্রাম |
| ইমরান | 10 | ঢাকা |
| লামিয়া | 8 | বরিশাল |

<Tip title="বাস্তব প্রজেক্টে * এড়িয়ে চলো">
`SELECT *` শেখার সময় সুবিধাজনক, কিন্তু আসল অ্যাপে **যে Column লাগবে শুধু সেগুলোর নাম লেখো।** এতে নেটওয়ার্কে কম ডেটা যায়, Query দ্রুত হয়, আর টেবিলে পরে নতুন Column যোগ হলে তোমার কোড হঠাৎ ভেঙে পড়ে না।
</Tip>

## WHERE: ছাঁকনি

ঢাকার ছাত্ররা কারা?

```sql
SELECT name, gpa FROM students WHERE city = 'ঢাকা';
```

| name | gpa |
| --- | --- |
| রাফি | 4.50 |
| তানভীর | 3.75 |
| সাদিয়া | 4.80 |
| ইমরান | 4.00 |

`WHERE`-এ এই তুলনাগুলো চলে:

| চিহ্ন | মানে | উদাহরণ |
| --- | --- | --- |
| `=` | সমান | `class = 8` |
| `<>` বা `!=` | সমান না | `city <> 'ঢাকা'` |
| `>` `<` | বড়, ছোট | `gpa > 4` |
| `>=` `<=` | বড় বা সমান, ছোট বা সমান | `gpa >= 4.50` |

```sql
SELECT name, gpa FROM students WHERE gpa >= 4.50;
```

| name | gpa |
| --- | --- |
| রাফি | 4.50 |
| নুসরাত | 5.00 |
| সাদিয়া | 4.80 |
| লামিয়া | 4.95 |

খেয়াল করো, SQL-এ সমান চিহ্ন একটা (`=`), অনেক প্রোগ্রামিং ভাষার মতো দুটো (`==`) না।

## ORDER BY: সাজানো

```sql
SELECT name, class, gpa FROM students ORDER BY gpa DESC;
```

| name | class | gpa |
| --- | --- | --- |
| নুসরাত | 8 | 5.00 |
| লামিয়া | 8 | 4.95 |
| সাদিয়া | 9 | 4.80 |
| রাফি | 8 | 4.50 |
| মীম | 9 | 4.25 |
| ইমরান | 10 | 4.00 |
| তানভীর | 8 | 3.75 |
| জুবায়ের | 10 | 3.50 |
| আরিফ | 9 | 2.90 |
| ফারিহা | 10 | NULL |

- `ASC` (Ascending) = ছোট থেকে বড়, এটাই ডিফল্ট, না লিখলেও চলে।
- `DESC` (Descending) = বড় থেকে ছোট।
- MySQL-এ `NULL`-কে সবচেয়ে ছোট মান ধরা হয়, তাই `DESC`-এ ফারিহা সবার শেষে, আর `ASC`-এ হতো সবার আগে।

একাধিক Column দিয়েও সাজানো যায়। প্রথমে ক্লাস অনুযায়ী, আর একই ক্লাসের ভেতরে GPA বেশি থেকে কম:

```sql
SELECT name, class, gpa FROM students ORDER BY class ASC, gpa DESC;
```

| name | class | gpa |
| --- | --- | --- |
| নুসরাত | 8 | 5.00 |
| লামিয়া | 8 | 4.95 |
| রাফি | 8 | 4.50 |
| তানভীর | 8 | 3.75 |
| সাদিয়া | 9 | 4.80 |
| মীম | 9 | 4.25 |
| আরিফ | 9 | 2.90 |
| ইমরান | 10 | 4.00 |
| জুবায়ের | 10 | 3.50 |
| ফারিহা | 10 | NULL |

<Remember>
**`ORDER BY` না দিলে ফলাফলের ক্রমের কোনো নিশ্চয়তা নেই।** ওপরের প্রথম উদাহরণে Row-গুলো `id` ক্রমে এসেছে, কিন্তু সেটা কাকতালীয়। টেবিল বড় হলে বা Index বদলালে ক্রম বদলে যেতে পারে। নির্দিষ্ট ক্রম দরকার হলে সবসময় `ORDER BY` লেখো।
</Remember>

## LIMIT: প্রথম কয়েকজন

মেধাতালিকার সেরা ৩ জন:

```sql
SELECT name, gpa FROM students ORDER BY gpa DESC LIMIT 3;
```

| name | gpa |
| --- | --- |
| নুসরাত | 5.00 |
| লামিয়া | 4.95 |
| সাদিয়া | 4.80 |

পরের ৩ জন (৪র্থ থেকে ৬ষ্ঠ), যেমন ওয়েবসাইটের "পেজ ২":

```sql
SELECT name, gpa FROM students ORDER BY gpa DESC LIMIT 3 OFFSET 3;
```

| name | gpa |
| --- | --- |
| রাফি | 4.50 |
| মীম | 4.25 |
| ইমরান | 4.00 |

`OFFSET 3` মানে "প্রথম ৩টা বাদ দাও"। পেজ নম্বর `p` আর প্রতি পেজে `n`টা হলে `OFFSET` হবে `(p - 1) × n`।

## DISTINCT: ডুপ্লিকেট বাদ

ছাত্ররা কোন কোন শহর থেকে এসেছে?

```sql
SELECT DISTINCT city FROM students;
```

| city |
| --- |
| ঢাকা |
| চট্টগ্রাম |
| সিলেট |
| রাজশাহী |
| খুলনা |
| বরিশাল |

ঢাকা চারবার ছিল, এখন একবার। একাধিক Column দিলে `DISTINCT` পুরো জোড়াটা দেখে:

```sql
SELECT DISTINCT class, section FROM students;
```

| class | section |
| --- | --- |
| 8 | A |
| 8 | B |
| 9 | A |
| 9 | B |
| 10 | A |
| 10 | B |

## Alias: সুন্দর নাম আর হিসাব

`AS` দিয়ে ফলাফলের Column-কে নতুন নাম দেওয়া যায়, আর `SELECT`-এর ভেতরেই হিসাব করা যায়:

```sql
SELECT name AS নাম, gpa * 20 AS শতাংশ
FROM students
WHERE class = 8;
```

| নাম | শতাংশ |
| --- | --- |
| রাফি | 90.00 |
| নুসরাত | 100.00 |
| তানভীর | 75.00 |
| লামিয়া | 99.00 |

Alias শুধু এই ফলাফলের জন্য; টেবিলে আসল Column-এর নাম বদলায় না। নামে স্পেস থাকলে ব্যাকটিক দাও: `` AS `পুরো নাম` ``।

## সব মিলিয়ে: লেখার ক্রম

একটা `SELECT`-এর অংশগুলো সবসময় এই ক্রমে লিখতে হয়:

```sql
SELECT   name, gpa          -- ১. কী দেখাব
FROM     students           -- ২. কোথা থেকে
WHERE    class = 8          -- ৩. কোনগুলো
ORDER BY gpa DESC           -- ৪. কীভাবে সাজাব
LIMIT    2;                 -- ৫. কয়টা
```

`--` দিয়ে শুরু হওয়া অংশ হলো **Comment**; MySQL এগুলো পড়ে না, শুধু মানুষের জন্য। (`--`-এর পরে একটা স্পেস দিতেই হবে।)

<BugMonster title="খুঁজতে গিয়ে">

**১. `Unknown column 'ঢাকা' in 'where clause'`**। লেখার মান উদ্ধৃতি ছাড়া দিয়েছ: `WHERE city = ঢাকা`। হবে `WHERE city = 'ঢাকা'`।

**২. ক্রম উল্টাপাল্টা লেখা।** `SELECT name FROM students ORDER BY gpa WHERE class = 8;` চলবে না, কারণ `WHERE` সবসময় `ORDER BY`-এর আগে।

**৩. `WHERE`-এ Alias ব্যবহার।**

```sql
-- ❌ Unknown column 'percent'
SELECT name, gpa * 20 AS percent FROM students WHERE percent > 90;
-- ✅ হিসাবটা আবার লেখো
SELECT name, gpa * 20 AS percent FROM students WHERE gpa * 20 > 90;
```

কেন এমন হয়, তার আসল কারণ লেভেল ৮-এ (Query-র Execution Order) বুঝব।

**৪. `DISTINCT` একটা Column-এ লাগাতে চাওয়া।** `SELECT DISTINCT city, name` লিখলে শহর একবার করে আসবে না, কারণ `DISTINCT` পুরো Row-এর জোড়া দেখে।

</BugMonster>
